Running Planner

Plan weekly mileage with natural language entry. Click a day to add a workout.

How to use this planner

Adding workouts

  • Click any day cell to open the editor, then type a workout in natural language.
  • Press Enter to save, Esc to cancel, Tab to save & advance to the next day.

Input examples

  • 8mi easy — 8 miles, Easy type
  • 5k tempo — auto-converts 5k to miles, Tempo type
  • rest or off — rest day
  • 10 long run — 10 miles, Long Run type
  • marathon — 26.2 miles, Race type
  • 6mi 5x5min uphill at threshold 1min rest — 6 miles, Intervals type, full text kept as notes
  • 45min bike — Cross-Train type

Workout types

  • Detected from keywords: Easy (easy, recovery, shakeout), Tempo (tempo, threshold, LT), Intervals (intervals, repeats, fartlek, speed, track, VO2), Long Run (long), Race (race, time trial), Cross-Train (bike, swim, yoga, strength, gym).
  • Unrecognized inputs default to Other. All original text is preserved as notes.

Navigation & editing

  • Drag and drop workouts between days to rearrange your week.
  • Use ◀ / ▶ arrows or keyboard ← / → to switch weeks.
  • The stats bar shows weekly mileage, change vs. last week, and flags increases >10%.

Exporting FIT files for Garmin

  • Export FIT downloads one .fit file per workout this week (rest days are skipped).
  • Import the .fit files into Garmin Connect via Training & Planning → Workouts → Import Workout.
  • Once imported, send the workout to your Garmin watch — it will appear under Training → My Workouts on the device.
  • Currently exports simple distance-based workout steps (sport = Running, target = open pace). Structured interval encoding is planned for a future update.

Data & privacy

  • All data is stored in your browser's localStorage — nothing is sent to any server.
  • Export JSON to back up your plan. Import JSON to restore or transfer between devices.
  • Export Markdown downloads the current week as a readable .md table.
