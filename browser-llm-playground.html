Current state

  • Modern browsers can run smaller quantized LLMs locally when navigator.gpu is available.
  • Best results today come from WebGPU-backed runtimes such as WebLLM; larger models still hit browser memory and download limits.
  • This page is a practical smoke test, not a benchmark. Success depends on browser version, GPU drivers, RAM, and available storage.
